# 🍰 SWEET LAYERS & GOLDEN CRUMBS

## 🇬🇧 English Description
This project is a modern web application designed to showcase a pastry brand. It consists of a landing page with an interactive form and a dynamic recipe section featuring a 3D visual experience.

### 🚀 Key Features
* **3D Carousel & UI**: Integrated Materialize CSS for a 3D rotating recipe slider with an auto-play function using jQuery.
* **Advanced CSS Animations**: Implemented custom @keyframes for "glowing neon" effects and smooth slide-down entrance animations.
* **Interactive Rating System**: Built a star-rating component that provides instant visual feedback using jQuery.
* **Responsive & Styled Forms**: A clean, user-friendly contact form with hover and active states for better user experience.


### 🛠 Technologies Used
* HTML5 & CSS3 (Flexbox, Transforms, Keyframe Animations)
* JavaScript & jQuery
* Materialize CSS Framework

## 🇹🇷 Türkçe Açıklama
Bu proje, bir pastane markasını tanıtmak için tasarlanmış modern bir web uygulamasıdır. Etkileşimli bir karşılama sayfası ve 3 boyutlu görsel deneyim sunan dinamik bir tarif bölümünden oluşur.

### 🚀 Öne Çıkan Özellikler
* **3D Carousel (Atlıkarınca)**: jQuery kullanarak otomatik dönen (auto-play) ve Materialize CSS tabanlı 3 boyutlu bir tarif kaydırıcısı entegre edildi.
* **Gelişmiş CSS Animasyonları**: "Neon parlama" efektleri ve yumuşak giriş animasyonları için özel @keyframes yapıları kullanıldı.
* **Etkileşimli Puanlama**: Kullanıcıların tariflere puan vermesini sağlayan ve jQuery ile çalışan anlık geri bildirimli yıldız sistemi oluşturuldu.
* **Modern Form Tasarımı**: Kullanıcı deneyimini artırmak için hover (üzerine gelme) ve active (tıklama) durumları eklenmiş şık bir iletişim formu tasarlandı.

### 🛠 Kullanılan Teknolojiler
* HTML5 & CSS3 (Flexbox, Dönüşümler, Animasyonlar)
* JavaScript & jQuery
* Materialize CSS Kütüphanesi
